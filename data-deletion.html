Data Deletion — Novel Browser

Last updated: October 23, 2026

How to delete your data

Novel Browser stores most data locally on your device. You can delete it at any time.

Delete from within the app

  1. Open Settings → Privacy & Data
  2. Select a time range (Last hour, 24 hours, 7 days, 4 weeks, or All time)
  3. Check the data types to delete: Cookies & Site Data, Browsing History, Translation Cache
  4. Tap Clear Data

Delete all local data

Uninstall the app. All local data is removed immediately.

What data is deleted vs. retained

Data type Deletion method Retention
Browsing history, bookmarks, cache, cookies, API keys, glossary Settings → Clear Data, or uninstall Until you delete
Usage analytics events and Analytics ID (optional, only if you chose to send usage data) Turn off sending in Settings → Privacy & Data (deletes automatically), or email request (see below) Deleted within 30 days of turning it off; deleted automatically 11 months after collection at the latest
Hashed device ID and usage (proxy quota) Email request (see below) Usage erased on request; see fraud-prevention row
Hashed device ID + free-tier-used flag (fraud prevention) Retained after deletion request Until no longer needed for abuse prevention (not personally identifiable)

Delete usage analytics

Usage analytics is off unless you turned it on. If you turned it on, you can delete everything that was sent without contacting us:

  1. Open Settings → Privacy & Data in Novel Browser
  2. Turn off Send usage data
  3. The app immediately sends one deletion request for every Analytics ID this device used. If the device is offline, it keeps the request and retries on the next launch or when the device is back online until it is accepted.
  4. We delete the matching events within 30 days. Events are also deleted automatically 11 months after they were collected, at the latest.

Settings → Privacy & Data lists every Analytics ID this device has used, so you can check what was deleted. You can also email badmumyo@gmail.com with subject Novel Browser Analytics Deletion Request and those Analytics IDs, and we will handle the deletion for you.

Usage analytics never contains page URLs, domain names, page titles, page text, translated text, text you type, your search queries, your reading log, or your advertising ID, so there is no such content to delete.

Request deletion of server-side data

  1. Open Settings → Privacy & Data in Novel Browser
  2. Copy your Deletion Request ID (8 characters)
  3. Email badmumyo@gmail.com with subject Novel Browser Data Deletion Request
  4. Include your Deletion Request ID in the message body

We process requests within 7 business days. Requests without a valid Deletion Request ID may not be processed.

Important: After deletion, server-side usage records are erased, but free translation quota is not restored. Subscription and BYOK features continue to work as before.
